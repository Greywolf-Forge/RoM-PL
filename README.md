# RoM-PL (Greywolf Forge)

Polskie teksty do Rise of Mankind: A New Dawn rev1093 dla Civilization IV: Beyond the Sword 3.19.

## Windows 10/11 PL: instalacja

Pobierz XML z Assets/XML/Text/ZZZ_GreywolfForge_Polish.xml lub paczkę z Releases. Skopiuj jeden XML do folderu moda Beyond the Sword/Mods/Rise of Mankind - A New Dawn/Assets/XML/Text/. W grze wybierz Polski, pozostaw oryginalny motyw Sylfaen.

Aby cofnąć zmianę, usuń ZZZ_GreywolfForge_Polish.xml. Nie podmieniasz oryginalnych plików. Nie ma instalatora, DLL ani fontów.

## Dla autorów modów

Plik zawiera tylko Tag i Polish, wraz z wymaganymi polami gramatycznymi. Można dołączyć go do moda albo scalić polskie teksty po Tag. Nie zawiera English, innych języków ani danych mechaniki. Manifest podaje wersję źródła i SHA-256. Przy zmianach modów zweryfikuj zgodność kluczy i reguł.

## Testy i prawa

XML sprawdzono statycznie i pod Wine/Xvfb z polskimi ustawieniami regionalnymi. Test na prawdziwym Windows 10/11 jeszcze nie został wykonany. Błędy zgłaszaj przez Issues.

Część tekstów pochodzi od wcześniejszych tłumaczy oryginalnego moda, część uzupełnił Greywolf Forge. Prawa pierwotnych autorów pozostają ich własnością. Greywolf Forge pozwala włączać własne poprawki do RoM i CoM z podaniem źródła. Oryginalny mod: https://www.moddb.com/mods/rise-of-mankind-a-new-dawn
